## 运行与构建边界

- `pnpm dev` / `pnpm build`：普通构建。工具搜索、参考层及窗口入口可用；工具内部明确提示当前构建未提供能力，不展示开发场景、预设样例或模拟完成动作。
- `pnpm dev:demo` / `pnpm build:demo`：显式本地体验构建，通过 `src-tauri/tauri.demo.conf.json` 使用 Vite `local-experience` mode。两种构建使用相同窗口服务；切换构建前完整退出旧应用。
- 本地体验构建进入工具后，可从独立“开发场景”区展开历史场景选择器；不放入 Home、设置或工具目录。开发选择仅在当前 WebView 运行内保留，完整重启恢复正常场景。
- 普通构建在编译时排除 `PanelDemo` 动态模块，不能通过 URL 参数或 UI 开关启用演示代码。没有新增依赖、IPC、权限或持久化。

## 界面与会话

`Panel.tsx` 管理工具目录、名称/别名过滤、无结果、方向键选择、Return 进入、返回空搜索及快捷键参考层。原生显隐、尺寸、会话和恢复焦点仍由[窗口服务](window-lifecycle.md)协调。切换期间禁用工具选择；Esc 仍可关闭。参考层使用 modal dialog、背景 inert 及焦点约束；第一次 Esc 关闭参考并恢复触发按钮，第二次关闭面板。

`PanelDemo.tsx` 仅提供本地演示状态；无 clipboard API、系统权限请求或 Base64 算法。工具页面始终标注未读系统剪贴板、未执行真实转换。当前色彩沿用暖白半透明、选中行暖橙强调；原生 HudWindow 材质沿用既有窗口服务，不把 CSS 或效果对象的存在当作背景模糊已通过。

- 历史：固定三条样例；开发区切换正常、空历史、权限不可用、条目不可用和复制失败。暂停读取 Rust 快照，按钮及 ⌘P 调用既有暂停命令，与托盘共享，退出重置。暂停不控制真实捕获。
- Base64：明确按钮选择编码、解码、URL-safe 或无效预设；自由编辑立即清除结果，提示本阶段未启用转换。方向/字符集只在仍处于预设状态时切换到明确对应的样例；编辑过的内容不会生成结果。Return 保留换行，⌘Return 仅在有结果时模拟完成。
- 完成：先显示“演示操作完成，未写入剪贴板”，1000ms 后调用当前会话关闭。组件卸载清除定时器；返回切换请求发出后，旧完成回调不能关闭仍处同一会话的新页面。错误不产生成功反馈。
- 草稿、结果、条目选择及反馈随工具卸载清空；面板按 Rust session 挂载，新会话从空搜索开始。系统减少动态时沿用窗口服务的立即切换与完成通知；反馈停留时间保持不变。

## 验证

先红后绿：新增演示测试最初因缺少 `PanelDemo` 模块失败；实现后通过。当前前端 21 项、Rust 23 项通过。新增覆盖自由编辑清结果、错误/空/权限/暂停状态、编码/解码/URL-safe/无效样例、延迟完成与卸载取消、别名/无结果/键盘选择、参考层两段 Esc 和触发按钮焦点，以及普通构建不可用边界。

本候选 `pnpm format:check`、`pnpm lint`、`pnpm typecheck`（含绑定漂移）、`pnpm test`、`pnpm build` 通过；`pnpm build:demo` 亦通过。普通构建 JS 已检查不含演示模块的预设无效输入和开发场景标记；本地体验构建应包含独立 PanelDemo chunk。

以下仍 **not verified**，不沿用旧占位界面的通过记录作为本候选证据：

- 原生面板中的长文、多行、窄工作区、键盘、减少动态及短录屏；当前工具不能可靠绑定 Quick Panel，详见[工具限制记录](evidence/lifecycle-acceptance-2026-11-17.md)。
- 同位置明暗文字/图案背景的材质开关对照、透明度/遮罩与可读性、系统减少透明度状态。尚未完成视觉调优，不判断延期项目已解决。
- 托盘/工具暂停跨窗口传播、完整重启重置、完成后恢复原应用焦点的最终组合实测。
- 独立 CR、远端 CI 及最终提交相关审批。

上述实质验收缺项使本候选保持 draft，不关闭本任务。[窗口协调](https://github.com/NibbleOrg/Nibble-desktop/issues/30)仍开放；可继续开发不等于其依赖或整体原生门槛已通过。

## 回退与发布

回退本候选前端文件、构建脚本和 demo 配置即可；没有用户数据格式变化或迁移。无公开安装包、更新入口或生产业务交付。快捷键可靠保存仍由[设置任务](https://github.com/NibbleOrg/Nibble-desktop/issues/33)交付。
