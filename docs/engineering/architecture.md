# 应用架构契约

Status: Current
Owner: 项目维护者
Last verified: 2026-11-13 — v1 规划契约；生产实现与实机行为未验证

一个 React 工程和一个 Rust 工程。前端按 Workbench、Quick Panel、共享组件与调用契约组织；Rust 按命令入口、应用服务、领域规则、存储和平台适配组织。共享模块不依赖具体界面外壳，业务规则不依赖 Tauri 或平台对象。

## 能力和状态

Capability 按能力定义操作和类型，无统一万能 execute。Quick Panel 静态目录负责名称、描述和入口，不加载插件；Calendar 不自动进入目录。两界面独立展示，通过核心共享状态，不直接发送业务命令。

Rust 核心拥有设置、持久数据、后台捕获、托盘、快捷键和应用生命周期；窗口挂载不启动服务，隐藏不终止后台。单服务故障不阻塞其他能力。React 拥有草稿、选择、内容布局和动画。Base64 运算和校验在 Rust，输入输出仅操作期间传递，不保存或记录。

## IPC 和同步

显式命令调用服务；入口校验输入及调用窗口身份，按最小权限授予。Quick Panel 可读/复制历史、使用 Base64，Workbench 管理设置；具体命令清单在实现中建立并测试。前端不直接访问文件、密钥和平台剪贴板，不能自报身份取得权限。

Rust 请求、响应、错误为唯一契约来源，生成前端类型并检查漂移，运行时仍验证。稳定错误类别和恢复信息映射到底层故障，UI 本地呈现，内容不进入错误或日志。

共享状态附递增版本：先订阅再读快照；读期间获知较新版本则继续读到覆盖最新已知版本，旧响应不能覆盖新状态；重连重新读取。通知只含类别与版本，无剪贴板正文。

设置修改由核心串行协调保存与生效，成功返回有效快照；注册失败保留旧可用快捷键。多项修改明确各项结果，具体恢复按类型定义。

## 窗口协调

Rust 统一协调 Quick Panel 显隐、原应用焦点和原生尺寸，React 管理内容和动画。每次打开新会话，工具切换及异步操作带请求版本；关闭、返回、切换使旧结果无效，不能重填内容、移动窗口或重开。无法取消的操作也不能影响新会话。

动画完成通知须匹配当前切换，有超时恢复；减少动态和界面异常不能无限阻塞生命周期。原生时序需实机验证。

## 数据与平台

统一剪贴板服务按序协调捕获、历史复制、Base64 排除复制及清空；旧捕获不得在清空后恢复已删除数据。历史与设置分别通过存储接口管理，密钥通过安全存储接口管理。底层文件/数据库由实现选择，满足容量、原子写入和恢复契约。数据规则见[隐私正文](../product/privacy.md)。

平台接口隔离标记、安全存储、焦点和窗口差异。v1 仅实现并验证 macOS，Windows 见[v4 规划](../operations/windows-v4.md)。未来 Calendar 边界见[扩展契约](calendar-future.md)。

## 验证与待实施选择

可替换时钟、存储、剪贴板、安全存储及窗口接口。自动化覆盖保留/去重、清空捕获竞态、设置回滚、过期请求、窗口切换、IPC 权限与输入校验；真实 macOS 验证权限、焦点、快捷键、窗口效果与更新。

底层存储格式、类型生成工具、精确模块路径、命令名和构建/测试命令均未实现；实施 issue 须给出具体选择与可执行验证。先实现可整体启动的双界面体验，再逐步实现复杂业务，不能削弱既定最终验收。
