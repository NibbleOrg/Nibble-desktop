# 项目与公开叙事

Status: Current
Owner: 项目维护者
Last verified: 2026-11-13 — v1 规划契约；生产实现与实机行为未验证

Nibble 是免费、个人维护的本地优先桌面工具。设计首先满足维护者日常需求，也面向需求相近且接受 Preview 限制的个人用户。Quick Panel 用于即时小任务，Workbench 用于需要持续上下文或空间的场景。当前能力范围见[产品契约](../product/contract.md)。

暂不规划收费、广告、商业服务、企业部署或团队协作；不承诺固定更新频率、响应时限和长期支持。未来商业边界变化需重新决策并公开说明。许可证以 [Apache-2.0 LICENSE](../../LICENSE) 为准，“免费”不构成额外许可限制。

以持续使用、流程顺畅程度、缺陷和主动反馈判断价值，不设增长/收入目标，不为统计引入自动遥测，下载量仅参考。公开说明采用[隐私正文](../product/privacy.md)的事实，说明更新联网、敏感文本风险、未公证和可丢弃历史。

首发 macOS Preview；Windows 11 x64 为 v4 目标，无日期承诺。v2/v3 及新增能力尚未确定。公开发布区分已发布、规划、未验证，不把 Preview 解释为稳定版交付期限。

沿用 Nibble、现有原型字标及视觉方向，发布图标为实施项；v1 不追加完整品牌系统或独立宣传网站。文档中文为主，保留英文术语与标识符，暂不维护完整双语版本。
