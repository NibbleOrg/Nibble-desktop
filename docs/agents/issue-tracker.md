# Issue 工作约定

Status: Current
Owner: 项目维护者
Last verified: 2026-11-13 — v1 规划契约；生产实现与实机行为未验证

使用 gh CLI 管理 NibbleOrg/Nibble-desktop。变更前读取相关 issue 正文、决议和依赖；产品、工程、数据、发布变更从 issue 开始，纯编辑修正可直接 PR。

普通 issue 须写目的与用户价值、可验证验收、非目标、依赖、验证方案和文档影响；bug 加复现、预期/实际及影响。父议题说明总目标，子议题说明交付范围和依赖；assignment 是工作认领，不另建 in-progress 标签。

Wayfinder 决策通过 resolution 关闭；普通实施 issue 仅在 PR 合并且验收验证后关闭。缺决策时交给维护者，不自行补产品承诺。依赖未解决不得宣称可端到端执行。分流见[标签](triage-labels.md)。
