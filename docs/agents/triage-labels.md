# 分流标签

Status: Current
Owner: 项目维护者
Last verified: 2026-11-13 — v1 规划契约；生产实现与实机行为未验证

普通开放工作 issue 恰有一个分流标签：

| 标签 | 条件 |
|---|---|
| needs-triage | 新输入尚待分类 |
| needs-info | 缺事实或人类决策；暂停通常转此 |
| ready-for-agent | 范围、验收、依赖和验证明确，可端到端执行 |
| ready-for-human | 需要人类判断或外部操作 |
| wontfix | 决定不做并关闭 |

不得将未充分定义的任务提升 ready。放弃用 wontfix；重新打开重新分流。Wayfinder map 和决策只使用 wayfinder:*，不混用普通分流。认领使用 assignment。
