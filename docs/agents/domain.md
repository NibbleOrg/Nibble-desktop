# 领域与 ADR

Status: Current
Owner: 项目维护者
Last verified: 2026-11-13 — v1 规划契约；生产实现与实机行为未验证

单上下文使用根 GLOSSARY.md 与 docs/adr/。术语只定义领域语言，不承载实现规格；明确术语时即时更新，避免同义词漂移。

ADR 仅在难逆转、缺背景会令人疑惑且存在真实取舍时建立。编号 NNNN-kebab-case.md；含 Title、Status、Date、Context、Decision、Consequences、Alternatives、References。Status 为 Proposed、Accepted、Rejected 或 Superseded by ADR-NNNN。

Accepted ADR 不改写、不合并删除；新方向用新 ADR 指明替代项。索引列编号、标题、状态、日期和替代关系，总蓝图关闭及每次发布核对链接和状态。
