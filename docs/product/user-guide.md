# 用户指南

Status: Current
Owner: 项目维护者
Last verified: 2026-11-13 — v1 规划契约；生产实现与实机行为未验证

当前只有决策材料与浏览器原型，生产安装包和以下功能均未验证。此指南描述已确认的目标行为。

1. 启动后在 Workbench 查看月份；首页可前后浏览和回到今天。
2. 使用 ⌥Space 唤起 Quick Panel，搜索并进入 Clipboard History 或 Base64。
3. 使用剪贴板历史前主动授权；请先阅读[隐私说明](privacy.md)。选择条目复制后自行粘贴。
4. Base64 输入文本并选择方向和字符集，复制有效结果。返回搜索或关闭会清空草稿。
5. 设置入口位于 Workbench 底部。⌘, 从 Quick Panel 打开其设置分组；工具、托盘和设置均提供相应捕获控制。
6. 窗口关闭保留后台运行，⌘Q 完整退出。完整快捷键见[交互契约](interaction.md)。

失败时先看操作旁原因；复制失败保留工具，捕获故障停止捕获并提供恢复入口。清空或重置前阅读确认提示；未确认不会破坏性重建。报告问题时只附自行审阅过的诊断信息。

安装、系统支持、Gatekeeper、更新和手动回装见[发布契约](../operations/release.md)。真实发布前须补齐实际下载入口、数据路径及操作截图，不能将规划表述为已可安装。
