# 用户指南

Status: Current
Owner: 项目维护者
Last verified: 2026-11-17 — Workbench 候选与浏览器操作核对；原生实机验收 not verified

当前源码已包含双窗口启动骨架与 Workbench 月历候选，尚无生产安装包。以下完整工具流程仍是已确认的目标行为，不表示生产业务已经交付。

本地追加候选在启动时将 Workbench 居中，四边距显示器可用区域等距，约占可用面积 80%（扣除菜单栏和 Dock）；随后可手动调整，隐藏重开保留当前尺寸。维护者已确认本地 UI 无问题；完整原生矩阵尚未验收。

本地运行 `pnpm dev` 后，Workbench 首页显示系统当前月份，公历固定六行；可用上个月、下个月和今天按钮浏览。系统地区决定日期标签和周首日，相邻月日期弱化，今天以暖橙色强调。底部齿轮进入设置，Home 返回月历并保留浏览月份。同次运行隐藏窗口保留路由与月份；完整退出后启动回 Home 当前月（原生隐藏/重启验收 not verified）。首页不显示工具或 Quick Panel 入口，也不读取系统日历或显示事件。设置当前仅显示快捷键注册状态，没有配置保存控件。验证记录见[Workbench 候选](../engineering/workbench-calendar.md)。

1. 启动后在 Workbench 查看月份；首页可前后浏览和回到今天。
2. 使用 ⌥Space 唤起 Quick Panel，搜索并进入 Clipboard History 或 Base64。
3. 使用剪贴板历史前主动授权；请先阅读[隐私说明](privacy.md)。选择条目复制后自行粘贴。
4. Base64 输入文本并选择方向和字符集，复制有效结果。返回搜索或关闭会清空草稿。
5. 设置入口位于 Workbench 底部。⌘, 从 Quick Panel 打开其设置分组；工具、托盘和设置均提供相应捕获控制。
6. 窗口关闭保留后台运行，⌘Q 完整退出。完整快捷键见[交互契约](interaction.md)。

失败时先看操作旁原因；复制失败保留工具，捕获故障停止捕获并提供恢复入口。清空或重置前阅读确认提示；未确认不会破坏性重建。报告问题时只附自行审阅过的诊断信息。

安装、系统支持、Gatekeeper、更新和手动回装见[发布契约](../operations/release.md)。真实发布前须补齐实际下载入口、数据路径及操作截图，不能将规划表述为已可安装。
